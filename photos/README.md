# Hardware photos

For inventory evidence, store actual photos in paths such as `photos/2026/11/P-20261122-001.jpg`.

The matching record in [the photo log](../intake/photos.json) links to the identified hardware IDs. Photos may show several devices, and multiple photos may support a single device.

Keep resolution sufficient to see silkscreen and connector details, but redact passwords, network QR codes, personal addresses, full serial numbers, and other private identifiers before committing. The repository is currently private, but photos should still be treated as sensitive.

If an image is available in chat but cannot be saved to this Git repository, record its intake description and mark `asset_status: not_stored`; do **not** pretend a link exists.
