## Images and identifications

- `P-20261122-171` — `1000063320.jpg`: Aether module back — `AETHER` brand, Chinese text 数字电位器 ("digital potentiometer"), `VCC(3V-5V) / VH(0V-5V) / VL(-5V-0V)`, yellow headers. → HW-0201.
- `P-20261122-172` — `1000063321.jpg`: Aether module front — chip legibly marked `X9C103S`, headers `GND / U/D / INC / CS / VCC` and `VH / VW / VL`. → HW-0201, high confidence. The X9C103S is a 10 kΩ, 100-tap digital potentiometer.
- `P-20261122-173` — `1000063322.jpg`: Electret microphone amplifier — large mic capsule, silkscreen `VCC:2.4-5.5V`, `Adjustable gain`, `OUT / GND / VCC`. → HW-0202. Layout matches the MAX4466 breakout; the amplifier chip is on the unphotographed reverse, so the IC is medium confidence.
- `P-20261122-174` — `1000063323.jpg`: Non-contact IR temperature module — metal TO-39 can with dark window, header `VIN / GND / SCL / SDA`. → HW-0203. This is the MLX90614 (GY-906) form factor; no legible model text, medium confidence.
- `P-20261122-175` — `1000063324.jpg`: Purple breakout, back only — pins `VIN / 3V3 / GND / SCL / SDA / SDO/SAO / NCS / CSB`, PCB code `HW-612`. → HW-0204. The HW-612 code and pin set match the documented GY-91 module (MPU-9250 nine-axis IMU + BMP280 pressure sensor; some documentation says BME280). Sensors not photographed — medium confidence; a front photo would confirm.
- `P-20261122-176` — `1000063325.jpg`: Small purple breakout — silkscreen `GY-B11`, `E/P` (partly obscured), `280`; pins `VCC / GND / SCL / SDA / CSB / SDO`. → HW-0205. The GY-BM E/P 280 board takes either a BME280 or a BMP280; the fitted chip is not clearly visible (board centre partly covered by a dark smudge), so the variant is undetermined.
- `P-20261122-177` — `1000063326.jpg`: CJMCU I2C multiplexer — silkscreen `TCA9548A` / `CJMCU`, chip marked `PW548A`, upstream pins `VIN / GND / SDA / SCL / RST / A0 / A1 / A2` and channel pairs SD0/SC0–SD7/SC7. → HW-0206, high confidence.
- `P-20261122-178` — `1000063327.jpg`: Purple module, back only — silkscreen `GY-219`, pins `VIN+ / VIN- / SDA / SCL / GND / VCC`, blue screw terminal edge visible. → HW-0207. GY-219 is the INA219 current/power monitor module; the chip side was not photographed — medium confidence.
