No matrix panel is attached, and none is counted.

- `P-20261122-170` — `1000063319.jpg`: Color sensor module — four clear LEDs around a central sensor aperture; headers silkscreened S0 / S1 / LED / GND and GND / OUT / S2 / S3 / VCC. → HW-0200.
